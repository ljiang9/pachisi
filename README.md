# Pachisi 十字戏

古印度贝壳棋盘游戏的终端极简实现。掷贝壳（简化为加权随机）走子，
吃子、安全格、终点道精确步数，全部 4 子到家者胜。

纯 Python 标准库，无第三方依赖。

## 玩法

- 2 或 4 人，每人 4 颗棋子，从营中出发
- 掷贝壳：7 颗贝壳的正面数决定步数；掷出 6 / 10 / 25 可进场，25 加回合
- 68 格外圈 + 11 安全格（安全格上不可被吃）
- 落到对方棋子所在格（非安全格）将其吃回营中，吃子加回合
- 终点道需精确步数进入，全部 4 子到家获胜

## 用法

```bash
python -m pachisi                  # 人机对战（你是玩家 0）
python -m pachisi --auto --games 20 --seed 42   # AI 对 AI 自动演示
python -m pachisi --players 2 --auto --games 10 # 双人对局
```

## 设计取舍

- 贝壳用加权随机近似真实贝壳分布（真实贝壳有固定概率表）
- 连续三次掷 6 作废等冷门规则未实现
- AI 只是 1 步贪心（到家 > 进场 > 吃子 > 进度 > 避险），不懂配合与封堵

## 真实验证记录

- `py_compile pachisi.py __main__.py` 通过
- 单元测试：吃子回营 / 安全格免吃 / 终点道精确步数（多一步被拒绝）/ 非法走法抛 IllegalMove
- `--auto --games 10 --seed 42` 全部正常结束
- 占位扫描：无 TODO/FIXME；`__pycache__` 已清理

## 诚实局限

- AI 很弱，熟悉规则的人类通常能赢
- 贝壳分布是近似值，非真实贝壳概率
- 文本回合制，无图形界面/存档/悔棋
- Python 3.10+
